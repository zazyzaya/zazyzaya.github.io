3. Some Simple Commands

The main reason you might like to use $\LaTeX$ for your homework assignments is that it makes writing math equations into a computer increadibly easy. You can tell the TeX renderer that you are beginning an "equation environment" using the dollar sign. One dollar sign for in-line equations, two for larger equation blocks.
For example, an in-line equation would be written as \$a^2 + b^2 = c^2\$ and rendered as $a^2 + b^2 = c^2$
An equation block will take up an entire line and be centered. We start these with two dollar signs.
E.g. \$\$ \sum_{i=1}^k = \frac{k(k+1)}{2} \$\$ becomes $$ \sum_{i=1}^k = \frac{k(k+1)}{2} $$ Now that we know how to start an equation environment, what do we actually put into it? $\LaTeX$ provides a huge number of useful math commands.
